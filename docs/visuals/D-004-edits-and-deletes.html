Decision brief · D-004 · 2026-11-22

What does an edit or a delete do to what people already have?

A changed message has already left marks: a feed row, a notification, a search entry. Existing products disagree or stay silent here, so this one is ours to choose.

Needs you

When something aimed at a person is taken back, what is left for them? I recommend C: no trace if they never saw it, a marker if they did, and a marker that stays if they kept it or it was flagged for them.

Already settled

Current truth

The feed, search and the notification tray always show the message as it is now.

Nothing jumps

A longer edit sits behind an expander, a shorter one keeps its space, a deleted message leaves a marker in its place.

Stable while viewed

Changes to the list apply when you move on, not under your eyes.

Taken back: three options

“Taken back” means the message is deleted, an edit removes your mention or the flag, or a reaction is removed.

A. Quiet

Once you move on, the row is gone and nothing says it was there.

Upside
The sender's right to take something back is fully respected.
Risk
You come back to something you read or kept and it is missing, with no explanation.

B. Transparent

A row always remains: “A message that mentioned you was deleted.”

Upside
Nothing ever disappears unexplained.
Risk
It announces that something was said and withdrawn, which defeats deleting a mistake and invites “what did you delete?”.

C. A trace only where you spent attention

Recommended

Respected where it costs you nothing, explained where you would otherwise be confused.

Upside
Neither surprises the reader nor exposes the sender.
Risk
More states to build and get right.

Option C, case by case

Where you were with itWhat you see after it is taken back
Not yet seenNothing. The row goes and the count drops with it.
On your screen right nowA marker in the same space, “Anna deleted this message”, until you move on.
Read earlierIn the Earlier list, the row shows the marker in place of the text.
Kept, or flagged for you StaysThe marker stays in Focus until you mark it done. You were told, or told yourself, to deal with it, so you should learn there is nothing left to do.

The other cases

What happensWhat it does
An edit adds a mention or a flagThe newly named person gets a new item, as if named from the start.
An edit removes a mention or a flagTaken back for that person: the table above.
An edit only changes the textThe row updates in place and shows “edited”. A read row does not become unread. A kept row shows “edited since you kept it”.
A reaction is removedThe grouped count follows. When the last one goes, the row is taken back.
A deleted message has repliesIts marker stays in the conversation for good, so the thread keeps its top.
SearchA deleted message is no longer found. An edited one is found by its new text only.
NotificationsNot yet sent: cancelled, or sent with the new text. Already sent: cannot be taken back; the tray entry shows “message deleted”.

On a phone-sized screen the marker has the same height as what it replaces, and an expander never opens by itself. Out for now: edit history beyond “edited”, and undoing a delete.
