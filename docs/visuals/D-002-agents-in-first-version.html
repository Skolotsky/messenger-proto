Decision brief · D-002 · 2026-11-22

How real are the AI agents in the first version?

Agents are already participants with Flag and Info. What is open is what drives them: a script or a real model.

Needs you

Pick what drives the agents. I recommend A now, scripted agents through the same door a real one would use, and one real assistant later, when the model arrives with the text rules.

Already settled about agents

In a conversation
  • A member of channels and threads
  • Can be mentioned and messaged directly
  • Messages carry a visible “agent” label
  • Shows a status: working, waiting on someone, done
In the feed
  • Text still streaming in: never
  • A finished progress update: Info
  • A result: no level, the usual rules
  • A stop for a human: flagged
In the product as launched
  • Agents belong to the team that connects them
  • We provide the door, not the agents
  • What the door promises is a later decision (D-008)

The three options

A. Scripted, through the real door

Recommended

A few agents in the seeded team follow written scenarios: post, work, write a reply piece by piece, stop and flag someone, continue when answered.

Upside
Runs with no model, key or cost. A demonstration plays the same way every time. Every agent behaviour can be shown on demand.
Risk
An agent cannot answer what it has no script for. We label it a demo agent and list it as a known shortcut.
Undo
Cheap: a real agent uses the same door.

B. Driven by a real model

Each agent calls a language model and answers whatever it is asked.

Upside
Feels real; closest to what early access teams will see.
Risk
Does not run without a key and a network. Replies vary, so “the agent stops and asks for approval” cannot be produced on demand. People judge the agent, not the feed.
Undo
Moderate.

C. Scripted, plus one real assistant

A, and one general assistant that answers free questions when a model is configured. Without a key it is absent.

Upside
Repeatable where it matters, real where someone pokes at it.
Risk
Two kinds of agent to build and explain. The model comes in early, before the feed is proven.
Undo
Cheap.

Why “A now, the assistant later”

  1. First: the feed, with scripted agents

    No model anywhere. Agents exercise status, streamed replies, Flag and Info through the door a team's own agent would use.

  2. Last: the model arrives with the text rules

    Text rules judged by a model are already in scope and built last. Once the model is there, one real assistant is a small addition.
