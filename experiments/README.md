# Experiments

Short, throwaway spikes that settle one question with evidence. One folder per experiment, `E-nnn-short-name/`, holding a `README.md` (question, method, result, conclusion) and whatever code was needed. How to run one: the `experiment` skill.

- Product code never imports from here.
- Every experiment ends with a conclusion that feeds a decision, even when the conclusion is "this does not work".
- Code quality rules are relaxed here. Honesty about results is not.
